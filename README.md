# Teaching materials

Live page: https://innotobe.github.io/teaching/

## Add materials
1. Put PDFs in a course folder: `<year>-<term>-<name>/` (e.g. `2026-fall-circuits/week01.pdf`).
   Optional `TITLE` file in the folder sets the display name.
2. Run `./publish.sh` — regenerates `index.html`, commits, pushes. The page updates in ~1 min.
