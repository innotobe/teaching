# Teaching materials

Live page: https://innotobe.github.io/teaching/

## Add materials
- **Browser:** open the course folder on GitHub → *Add file* → *Upload files* → drag PDFs → *Commit changes*.
- **Server:** copy PDFs into the course folder, then run `./publish.sh`.

The index page lists every PDF automatically, grouped by folder; it updates ~1 min after each upload.
Course folders: `<year>-<term>-<name>/`. Display titles live in `_data/courses.yml`.
